All three print "Measure by B&K 5128". No other file was used.

These charts show a single JT7 trace each, so this data set is ONE channel.
There is no left/right split here.

Calibration: plot box 1339x573 px, x = 20 Hz..20 kHz log, y = +25..-25 dB.

Consistency of the three screenshots:
  After 1 kHz alignment the traces agree to RMS 0.11 dB (max 0.66 dB).
  Their absolute 1 kHz level differs by 1.11 dB, which is a placement
  difference between screenshots, not a difference in the data:
    -0.98, +0.13, -0.06
  Coverage: 155329 is complete; 155349 misses part of 3.0-3.4 kHz and a few
  other short stretches; 155402 has the red trace hidden under the blue FT1Pro
  curve in several bands (notably 0.13-0.30 kHz, 3.6-4.0 kHz).
  The average uses every image that covers a given frequency.

Limitations:
  - These are screenshots of a chart, not measurement files. Expect about
    +/-0.3 dB from pixel reading in 100 Hz - 8 kHz and rather worse above
    15 kHz where the trace is steep.
  - chart offset column is the mean vertical placement of the three
    screenshots and is not a calibrated playback level.
  - A single trace means no channel-matching information can be given.
